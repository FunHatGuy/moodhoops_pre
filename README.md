# Moodhoops – Shopify theme

Theme code for the Moodhoops Shopify store (soft launch at **new.moodhoops.com**).

- **Source:** the store's "Production" theme (based on Xclusive 3.1.0), exported from Shopify admin on 2 Nov 2026.
- **Layout:** standard Shopify theme folders at the repo root (`assets/`, `config/`, `layout/`, `locales/`, `sections/`, `snippets/`, `templates/`), so this repo can be connected with Shopify's GitHub integration.

## Connecting to Shopify

In Shopify admin: **Online Store → Themes → Add theme → Connect from GitHub**, choose this repo and the `main` branch. Shopify adds it as a new, unpublished theme that stays in sync with the branch. The live theme is not changed until you publish the connected one.

Note: once connected, edits made in the Shopify theme editor are committed back to the branch by Shopify. Pull before editing locally.
